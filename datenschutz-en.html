hosting via github pages

this website is hosted via GitHub Pages, a service provided by GitHub, Inc.

when you visit the website, technically necessary connection data is processed. this includes, in particular, the IP address. GitHub states that it logs and stores the IP addresses of visitors to GitHub Pages websites for security purposes.

insofar as this processing falls within our responsibility, it is based on our legitimate interest in providing this website securely and reliably pursuant to art. 6(1)(f) GDPR.

more information on data processing by GitHub can be found in GitHub's privacy statement (opens in new tab).

adobe fonts

we use Adobe Fonts, a service provided by Adobe, to display our typefaces.

when you visit our website, the required font files are loaded from Adobe's servers. this may transmit information such as the fonts used, the web project ID, the hostname of the page visited, and the IP address.

Adobe states that it receives the IP address to deliver the fonts but does not store it. according to Adobe, Adobe Fonts does not set any cookies when serving web fonts.

insofar as this falls within our responsibility, the integration is based on our legitimate interest in a consistent and visually fitting presentation of our website pursuant to art. 6(1)(f) GDPR.

more information on data processing by Adobe Fonts can be found in Adobe's privacy notices (opens in new tab).

data transfers to third countries

using GitHub Pages and Adobe Fonts may result in personal data being processed outside the European Union or the European Economic Area, in particular in the USA.

according to their own statements, the providers base such data transfers on appropriate data protection safeguards, in particular the European Commission's standard contractual clauses and, where applicable, the EU-U.S. Data Privacy Framework.

more information on international data transfers can be found in the respective providers' privacy notices.
